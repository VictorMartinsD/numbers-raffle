# Numbers | Sorteador de Números

Aplicação web responsiva para sorteio de números personalizados, desenvolvida como um desafio prático de Frontend para consolidar conceitos de manipulação dinâmica do DOM, estilização moderna e validações de formulários.

> **Status do Projeto:** 🚀 Em desenvolvimento

## 🎯 Funcionalidades Principais

- Escolha da quantidade de números a serem sorteados.
- Definição de intervalo customizado (valor mínimo e máximo).
- Opção de sorteio sem repetição de números.
- Exibição dos resultados em tempo real com animações.

## ⚠️ Validações do Sistema

- Bloqueio de campos vazios.
- Garantia de que o valor máximo seja maior que o valor mínimo.
- Validação para impedir que a quantidade de números seja maior que o intervalo disponível (quando a opção de não repetir estiver ativada).
- Exibição de mensagens de erro amigáveis para o usuário.

## 🛠️ Tecnologias Iniciais

- HTML5
- CSS3
- JavaScript (Vanilla)
